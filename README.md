# 실습과제 #3 : 살아 움직이는 영화 보드
- 이름 / 학번 : (입력)
- 사이트 주소 : https://mydave0321maker.github.io/web-hw3/
- 사용 자료 : TMDB 영화 정보 및 포스터, KOBIS 일별 박스오피스 (기준일: 확인 후 입력)

## 구현 항목 체크
| 요구사항 | 상태 | 한 줄 메모 |
|---|---|---|
| 1 렌더링 | 구현함 | 영화 객체 10개, 포스터 주소 확인 필요 |
| 2 검색 | 구현함 | 제목 실시간 검색 |
| 3 정렬 3종 | 구현함 | 평점, 연도, 제목 |
| 4 보기 필터와 getView | 구현함 | 세 조건 통합 |
| 5 찜과 저장 | 구현함 | 이벤트 위임과 localStorage |
| 6 빈 결과 | 구현함 | 안내 문구 표시 |
| 7 상세 대화상자 | 일부 | 대화상자 구현, TMDB 줄거리 확인 필요 |
| 8 이벤트 및 콘솔 | 일부 | 인라인 이벤트 없음, 배포 후 콘솔 확인 필요 |
| 보너스 다크 모드 | 구현함 | 테마 저장 |

## 어려웠던 점 3가지와 해결
- 검색과 정렬의 결합: getView에서 순서대로 처리하는 구조를 적용했다.
- 카드 재렌더링과 찜: 보드 이벤트 위임을 사용했다.
- 새로고침 후 상태 유지: localStorage에 배열을 JSON으로 저장했다.
