# 실습과제 #3 : 살아 움직이는 영화 보드

- 이름 / 학번 : 김민재 / 학번 입력
- 사이트 주소 : https://mydave0321-maker.github.io/web-hw3/
- 사용한 API : TMDB(포스터, 영화 정보), KOBIS(박스오피스, 기존 과제 데이터)

## 구현 항목 체크(기능 체크표)

| 요구사항 | 상태 | 한 줄 메모 |
|---|---|---|
| 1. 렌더링 | 구현함 | 영화 데이터 10건을 카드로 자동 생성 |
| 2. 검색 | 구현함 | 제목을 입력할 때마다 검색 결과 표시 |
| 3. 정렬 3종 | 구현함 | 평점순, 최신순, 가나다순 정렬 |
| 4. 보기 필터와 getView | 구현함 | 검색, 필터, 정렬 조건을 함께 적용 |
| 5. 찜과 저장 | 구현함 | localStorage를 이용하여 찜 상태 유지 |
| 6. 빈 결과 | 구현함 | 검색 결과가 없을 때 안내 문구 표시 |
| 7. 상세 대화상자 | 구현함 | 포스터, 제목, 개봉일, 평점, 줄거리 표시 |
| 8. 이벤트 및 콘솔 오류 | 일부 | 이벤트 분리 구현, 콘솔 최종 확인 필요 |
| 보너스: 다크 모드 | 구현함 | 다크 모드 전환 및 설정 저장 |

## 어려웠던 점 3가지와 해결

1. 일부 영화의 포스터가 표시되지 않는 문제가 발생했다. TMDB 이미지 주소의 대소문자와 숫자를 확인하고 올바른 주소로 수정하였다.
2. GitHub Pages에서 404 오류가 발생했다. 저장소의 Pages 설정과 사이트 주소를 확인하여 해결하였다.
3. HTML과 CSS 코드가 한 줄로 표시되어 읽기 어려웠다. 브라우저 VS Code의 문서 서식 기능을 이용하여 줄바꿈과 들여쓰기를 정리하였다.

- 답변 요약 : 영화 카드 렌더링, 검색, 정렬, 필터, 찜 저장, 상세 대화상자, 다크 모드 구현 코드와 오류 해결 방법을 제공받았다.
